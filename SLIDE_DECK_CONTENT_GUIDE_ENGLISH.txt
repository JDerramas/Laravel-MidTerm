SLIDE 5: DATABASE ARCHITECTURE & SCHEMA INTEGRITY
================================================================================
• LAYOUT: Left Side: 7 Core Tables Summary; Right Side: Entity-Relationship Diagram (ERD).

• EXACT ON-SLIDE TEXT:
  [Slide Title]: Database Architecture & Schema Integrity
  [Subtitle]: TiDB Serverless Cloud on AWS Singapore (MySQL 8.0 Compatible)

  [The 7 Core Normalized Tables]:
  1. products: Dynamic JSON size counts and atomic stock units.
  2. reservations: Student checkout records with frozen JSON cart snapshots.
  3. support_tickets: Customer inquiry tracking (Open, In Review, Resolved).
  4. support_messages: Real-time chat history with ON DELETE CASCADE.
  5. system_users: Role-based admin directory (Faculty advisers and council officers).
  6. students: Local verified student roster cached from OnePass tokens.
  7. activity_logs: Immutable security audit trail recording all system actions.

  [Key Architectural Highlights]:
  • JSON Snapshot Pattern: Guarantees 100% historical accuracy for order receipts.
  • Cascading Foreign Keys: Purges orphaned messages upon ticket deletion.
  • ACID Transactions: Guarantees zero stock desynchronization during checkouts.

• RECOMMENDED VISUAL:
  - Clean ERD diagram illustrating relationships between reservations, support tickets, and products.

• SPOKEN PRESENTER SCRIPT (Member 3):
  "Our data persistence layer consists of seven normalized tables managed by MySQL's
  InnoDB engine. We adopted the JSON Snapshot Pattern for orders to ensure that future
  product price or description updates never alter historical customer receipts. We also
  implemented Foreign Key Cascades to automatically prevent orphan records, and database
  transactions to guarantee atomic inventory deductions during simultaneous checkouts."

III. SLIDE DESIGN RECOMMENDATIONS (POWERPOINT / CANVA)
================================================================================
1. Color Palette:
   - Background : Deep Navy Slate (`#0f172a` or `#1e293b`) for an executive dark-mode look.
   - Headers    : Pure White (`#ffffff`) with ICS Gold (`#f59e0b`) accents.
   - Card Borders: Subtle Slate Slate (`#334155`).

2. Typography:
   - Headings: Space Grotesk, Montserrat, or Plus Jakarta Sans (Bold/Black weight).
   - Body Text: Inter, Open Sans, or Roboto (Clean, readable sans-serif).

3. Presentation Best Practice:
   - Keep on-slide text brief and scannable. Rely on the Spoken Presenter Script for
     the complete verbal narrative during your defense!
