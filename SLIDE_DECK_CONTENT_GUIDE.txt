SLIDE 5: DATABASE ARCHITECTURE & SCHEMA HIGHLIGHTS
================================================================================
• LAYOUT: Kaliwa ay Schema Table List; Kanan ay ERD Diagram snapshot.

• EXACT ON-SLIDE TEXT:
  [Slide Title]: Database Architecture & Schema Integrity
  [Subtitle]: MySQL 8.0 InnoDB Engine with Full ACID Compliance

  [Core Tables (7 Normalized Tables)]:
  1. products: Catalog inventory with JSON size counts & atomic stock units
  2. reservations: Order records with JSON shopping cart snapshots
  3. support_tickets: Customer service cases (Open, In Progress, Resolved)
  4. support_messages: Chat conversation history with ON DELETE CASCADE
  5. system_users: Role-Based Directory (Advisers & Officers kabilang ang ics@npc.edu.ph)
  6. students: Local verified student roster cached from OnePass
  7. activity_logs: Immutable Whiteboard Audit Trail (User Code, Action, Activity, Time)

  [Key Database Design Highlights]:
  • JSON Snapshot Pattern: Tinitiyak ang historical price at size accuracy ng orders.
  • B-Tree Indexing: Mabilis na O(log N) lookups sa student_id at reference codes.
  • Orphan Prevention: ON DELETE CASCADE sa support_messages para malinis ang database.

• SUGGESTED VISUAL:
  - ASCII o visual ERD diagram mula sa `README.md` o `EXPLAIN_DATABASE.txt`.

• PRESENTER SCRIPT (Member 3):
  "Ang aming data layer po ay binubuo ng pitong (7) normalized tables sa ilalim ng 
  MySQL InnoDB storage engine. Gumamit po kami ng JSON Snapshot Pattern para sa shopping 
  cart items upang manatiling accurate ang presyo kahit magbago ito sa future. Mayroon 
  din po kaming B-Tree indexes sa student IDs para sa sub-millisecond search latency, 
  at foreign key cascading upang maiwasan ang orphan records sa chat."

III. QUICK TIPS PARA SA INYONG SLIDE DESIGN SA CANVA O POWERPOINT
--------------------------------------------------------------------------------
1. Kulay ng Slides:
   - Background: Dark Navy Slate (`#0f172a` o `#1e293b`). Mas mukhang high-tech at professional.
   - Text Titles: White (`#ffffff`) at ICS Gold (`#f59e0b`).
   - Cards/Boxes: Dark slate na may subtle borders (`#334155`).

2. Font Pairings:
   - Headings: Space Grotesk, Plus Jakarta Sans, o Montserrat (Bold/Black).
   - Body Text: Inter o Arial (Clean and readable).

3. Iwasan ang Text Clutter:
   - Huwag ilagay ang buong talata sa slide. Gamitin ang bullet points na nakasulat 
     sa itaas, at sabihin na lamang sa bibig ang nasa Presenter Script!
